# JjBiTV v7：多网盘片库与独立放映室

## 用户流程

`/pan` 是云端片库，支持阿里云盘、夸克筛选，关键词搜索、继续查找更多、优先排列标题标注的 4K 资源，以及粘贴分享链接。

点击「进入放映室」进入 `/pan/watch`。桌面使用主播放器加右侧目录，手机使用播放器在前、目录在后的布局。搜索结果不会和播放器堆在同一页面。

- 阿里云盘：官方 App 扫码登录、公共分享目录、个人资源库目录、直接播放、确认后单文件转存、重复转存复用、画质切换、Range 与 HLS 代理。
- 夸克：保留 v6 的扫码、单集转存与试看；增加原文件尺寸和当前可播尺寸的区分。
- 转存操作有文件名与大小确认，仅保存一个选中文件。连播默认关闭，转存模式启用连播时明确提示会逐集占用空间。
- 观看进度仅存本机；试看与完整线路分开记录。断开账号不删除网盘文件。

## 来源与验证

在用户服务器上检查了数十个候选接口。保留原先的木偶网盘、夸克影视、夸克 4K 社区，新增小云搜索、影盘社、花卷影视、电影云集，总计 7 个检索适配器。电影云集和部分旧来源在验证过程中发生 403 或超时，按来源独立熔断；不以“添加了来源”宣称所有来源始终可用。

小云搜索同时查询夸克和阿里索引，影盘社使用实际支持的 `ALY` / `QUARK` 类型。第一批结果立即流式输出，服务端成功搜索缓存 5 分钟；单来源 10 秒预算，连续两次失败后冷却 5 分钟。分页缓存与网盘筛选分别隔离。分享链接按标准域名归一化去重。

以《战狼2》《血战钢锯岭》进行了服务器侧实际搜索、分享凭证和目录验证。修复数字片名的匹配：`战狼2.2017`、`战狼 1-2` 可匹配《战狼2》，`战狼.2015` 不可。资源标题的 4K 标记与播放器实际画质独立展示。

阿里分享预检有节流；超过预检预算或遇到限流时标记「打开时检测」，不会错误地判成失效。打开目录时重新验证。已验证分享可访问不等于已验证所有文件的完整播放。

参考接口结构的公开源代码：

- [PanSou 插件目录](https://github.com/fish2018/pansou/tree/main/plugin)：只参考格式，没有执行远程 JAR、Spider 或使用共享账号 Cookie。
- [阿里官方扫码流程的开源实现](https://github.com/ImYrS/aliyundrive-qr-login/blob/main/modules/login.py)。本站直接请求 `passport.aliyundrive.com`，不经过第三方授权中转。
- [OpenList 阿里云盘驱动](https://github.com/OpenListTeam/OpenList/tree/main/drivers/aliyundrive) 与 [分享驱动](https://github.com/OpenListTeam/OpenList/tree/main/drivers/aliyundrive_share)。

## 画质与时长的真实边界

2026-10-26，使用用户本人扫码的账号验证：

| 样本与方式 | 实测 |
| --- | --- |
| 夸克已有样本原文件 | 3840×2160、60fps、HEVC、HDR，约 4.48 GiB |
| 夸克网页完整线路 | 480×270，高清/4K 条目标记不可访问 |
| 夸克分享试看 | 1440×810，实际 HLS 121 秒 |
| 阿里《血战钢锯岭》分享预览 | 1920×1080，实际 HLS 120 秒 |
| 阿里该片转存后的完整线路 | 1280×720，实际 HLS 约 8359 秒，浏览器起播确认 |

用户反馈同一夸克文件在官方 App 可完整高清播放，因此这些结果只描述当前网页接口与连接，不能推断账号在所有终端都只能低清。新增资源数量也不能突破网盘向当前接口开放的画质与速度。

阿里接口可能同时返回完整 `url` 与限时 `preview_url`。服务端读取各条 HLS 的实际时长，与源时长比较后标记限时线路，并优先选完整线路，再比较分辨率。不会将 1080P 两分钟样片优先于完整 720P。原文件地址为空时不显示虚假的原画选项。

为验证转存，用户的阿里云盘「JjBiTV 追剧」目录中保留了一份约 3.70 GiB 的《血战钢锯岭.mp4》，保存映射持久化，后续测试和播放均复用。没有批量保存或自动删除。

## 接口与持久化

- `/api/netdisk/search`：`provider` 可选 `aliyun` / `quark`，`page` 为 1–10，NDJSON 逐批响应。
- `/api/alipan`：状态、扫码生成与轮询、断开、目录、直接播放、确认转存后播放。所有请求要求站点登录，写请求要求同源。
- `/api/alipan/media`：受登录保护的短期播放票据。仅允许已知阿里 CDN 域名，逐次检查重定向、DNS 与地址；不向 CDN 发送账号 Token。
- 阿里 Token 独立存放 `alipan-credentials.enc`，AES-256-GCM、0600 权限，与 `quark-credentials.enc` 分离。沿用 `CLOUD_ENCRYPTION_KEY`。
- 二维码绑定发起浏览器，换码/断开会撤销旧登录。凭证刷新保留当前账号的转存映射。账号更换后旧播放票据失效。
- 网络中断后的未知转存结果不会自动重复提交，需要在官方目录确认；明确拒绝则解除未完成标记。

## 验证

覆盖二维码隔离、取消登录竞态、凭证加密、提取码与域名归一化、同名续集/年份区分、分页缓存、来源失败隔离、单文件转存、并发复用、未知写入状态、限时与完整线路排序、HLS 改写和登录/同源边界。

Playwright 检查 1440×1000 桌面和 390×844 手机视口、键盘选集、转存取消、布局分离、画质切换，以及真实账号的完整 720P 与 1080P 试看。模拟交互截图与真实播放截图分别保存，不将模拟媒体作为真实账号播放证据。
