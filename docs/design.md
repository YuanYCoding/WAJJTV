# WAJJTV 设计约定

- 首页是日常选片与搜索界面，使用炭黑 `#101111`、暖金 `#d7b574`、米白正文，细分隔线，6 列海报；手机 3 列。
- 标题：今晚，和你一起看。副标题：海清和静静自用追剧资源。
- 首页右侧由用户合照衍生的两个人物坐在金色放映台上；手机端缩小。人物文件通过鉴权接口提供，不进入公开源码仓库或 Docker 构建上下文。
- 发现区域保留真实海报、标题、评分与分页；分电影、剧集、动漫、综艺、排行榜。过滤由上游执行，不将当前页过滤冒充完整片库筛选。
- 海报不标注未经实测的画质；数据源健康和播放清晰度分开描述。
- 沿用 LibreTV 的播放器、设置抽屉、主题、历史数据存储键，保留上游署名与 AGPL 许可证。
