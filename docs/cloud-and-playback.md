# WAJJTV v3：播放与网盘

## 播放源

2026-10-23 从 TVboxorg/TVbox、qist/tvbox、zhbjzhql1/TVBox、hello2z/TVbox-API、oooopera/moontv_config、Wolfun/luna-moon-tv-api、smallmain/moontv-aggr-config、gxnas/666zmy-MoonTV-config 收集普通影视接口。测试 232 个基础地址、179 个 JSON 变体，并用生产环境 Node 运行时复核 183 个首次失败地址。

9 个新增地址完成正片 HLS 清单与开头/中段分片检查，AES-128 HLS 按公开清单正常解密，再使用 ffprobe 检查编码。8 个是已有供应方的备用接口，艾旦影视是新增供应方；不可将 9 条地址描述为 9 个独立片库。测试只说明抽样时可用，不保证全库、全天、所有地区可播放。完整样本和检索时间见 [source-audit-v3.json](source-audit-v3.json)。

TVBox 的 type=1 CMS JSON 接口可按现有订阅入口导入，M3U 直播订阅另行处理。Spider/JAR/JS/Python 站点依赖盒子运行环境，不能把配置地址直接当 CMS 使用。本项目不执行订阅中引用的可执行插件。

每个供应方优先使用近期响应较快的健康地址，备用域名不重复参加同一次搜索。仍采用 2 次失败暂停、后台 5/15/30/60 分钟复检的策略。新增地址追加到 DEFAULT_SOURCES，保留既有 env_N 标识。

## 搜索与观影

- 第一页立即输出；后续分页最多再等待 2 秒，失败时保留已取得的结果。
- 完整成功的单源结果缓存 90 秒，聚合结果缓存 60 秒。缓存不能绕过失效源状态，部分失败不会被缓存为完整结果。
- 刷新搜索链接时等待异步源配置加载，防止将初始化空列表缓存 5 分钟。
- 换源候选逐个出现，详情检测并发为 3；已检测完成的候选可直接操作。详情耗时不标成实际播放带宽。
- 搜索卡片在更多源返回时保留展开状态。页面提供影院宽屏、15/30/60/90 分钟定时暂停。
- 双人插画使用服务器内存缓存、ETag 和浏览器私有缓存；每次复用前验证登录，匹配返回 304。公开海报保持已有 30 天缓存，并异步解码。
- 普通首页的“三级／伦理”入口已移除，原有分类数据及推荐隔离规则保留。

## 阿里云盘连接

入口 `/cloud`。通过 OpenList 的公开授权服务 `https://api.oplist.org` 创建官方阿里云盘二维码，用户使用阿里云盘 App 扫码并确认后，点击“我已扫码，完成连接”。本版没有接入其他网盘，也没有导入他人分享的账号 Cookie。

授权服务是 OpenList 提供的第三方服务；二维码指向 `https://openapi.alipan.com/oauth/qrcode/...`。授权范围由阿里云盘确认页展示。网站只调用目录读取与视频预览接口，不提供网盘上传、删除、移动或分享操作。

连接为家庭共用：拥有网站密码的海清和静静都可以浏览该账号的视频目录。站点密码不是网盘隔离账号。普通账号可尝试连接，但可选清晰度、转码状态、容量及播放速度以网盘实际响应为准。

`CLOUD_ENCRYPTION_KEY` 为部署者生成的独立 32 字节随机密钥，使用 64 位十六进制配置。凭证使用 AES-256-GCM 加密保存在持久化目录的 `cloud-credentials.enc`（0600）。前端不会接收 access/refresh token，也不写入 localStorage。备份时必须保留 `.env` 中的密钥和加密文件。

所有 API 必须通过网站密码登录；写请求校验 Origin。二维码请求绑定发起浏览器、5 分钟失效，新请求或断开操作会使旧请求失效。刷新凭证合并并发，断开后进行中的刷新不能复活旧连接。

云盘媒体使用短期随机标识；页面不直接获得带签名的上游地址。播放清单、分片、密钥、Range 请求通过同源接口处理，并逐跳校验公网地址。媒体响应不进入公共缓存。重启或播放标识失效后重新打开影片即可申请新地址。

## 验证边界

自动测试覆盖凭证加密、跨浏览器二维码拒绝、断开取消授权、目录过滤、媒体失效、同源/登录检查、首批分页输出和缓存失效检查。浏览器验证包含真实二维码生成，目录/媒体 UI 使用测试账号响应及本地生成 H.264 视频验证，不能替代用户真实网盘授权后的播放验收。
