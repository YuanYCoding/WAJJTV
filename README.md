# JjBiTV

海清和静静自用追剧资源。由 WAJJTV 演进，基于 [LibreTV](https://github.com/LibreSpark/LibreTV) 的私人影院版本。

- 深色暖金界面、专属双人角色、电脑与手机适配。
- 电影、剧集、动漫、综艺片库，类型/地区/年代筛选、评分与热度排序、分页加载。
- 豆瓣/百度榜单与 Bangumi 本周放送。
- 多源并发流式搜索、备用接口去重；失效源暂时隔离，后台复检成功后恢复。
- 第一页先显示、成功源单独缓存、较快的健康接口优先；换源候选逐个就绪。
- 网盘追剧：10 个检索适配器，递归确认目录含视频后才展示；阿里/夸克标签本地筛选，返回时恢复结果、筛选和滚动位置。
- 云端片库与私人放映室分开，搜索整张卡片可打开；“播放”弹窗实时显示容量检查、清理、转存、画质获取，准备好后确认播放。
- 网盘播放器采用 ArtPlayer + HLS.js，支持拖动进度、前后跳转、倍速、画中画、全屏和断点续播。普通播放仅使用完整线路。
- 专用网盘账号可开启容量不足自动清理；保留本站活跃播放资源，文件超过账号总容量时直接提示，不执行清理。
- 原文件地址可用时默认原画；原画受限或浏览器不兼容时，提供完整转码、官方网盘及外部播放器备选。外部观看可保留文件 6 小时。
- 经过实际 CORS 验证的媒体分片直接从网盘 CDN 加载，失败后回退服务器；可手动启用持续缓冲降档。
- 左侧“其他资源”为独立 HLS 检索：21 个可管理接口（16 个默认启用、5 个备用），解析 m3u8 并读取视频分片尺寸；收录 79 条达到 4K 编码尺寸且满足长片条件的候选，搜索时重新验证，不按片名或码率认定 4K。支持 1080P / 已测 4K 筛选与已有 m3u8 播放。
- 夸克容量清理以实际容量释放为准；移入回收站足够腾出空间时，不再强制永久删除，避免回收站 15000 中断播放准备。仅对幂等读取做一次短暂重试，不自动重放不确定的转存。
- 设置内管理网盘和 M3U8 接口，服务端持久化、乐观版本校验，支持增删改、启停、测试；网盘可添加 PanSou / JSON / CMS 公开搜索接口。
- 修复普通代理对大分片响应体的短超时、HLS 直连前的重复拉取和缓存读取失败的加载挂起；预取让位于当前播放，按码率控制缓冲内存。播放器提供缓冲、丢帧诊断及画质／流畅优先策略。
- 影院宽屏、定时暂停，私人插画 ETag 缓存与异步海报解码。
- 沿用 LibreTV 播放器、观看历史、收藏、直播与配置格式。
- 影片详情预览，并可带片名跳转到网盘搜索。现有界面沿用线上 JjBiTV v4 的简化入口；旧片单数据保留。

## 本地运行

```sh
npm ci
# 在 .env.local 中配置 PASSWORD 与 DEFAULT_SOURCES
npm run dev
```

私人角色可放到 `private/mascots.png`。该目录不入库、不进入镜像；图片接口要求登录。缺少图片时显示 W & J 字样。应用沿用原有 LibreTV 数据存储键，升级不会主动删除观看历史。

当前部署的情侣头像图标也不上传公共仓库。自行部署时请在构建前放入自己的 `public/icons/jjbitv-192.png`、`public/icons/jjbitv-512.png` 与 `public/favicon.ico`；现网构建使用私有备份中的素材。

```sh
npm run typecheck
npm run lint
npm test
npm run build
```

## 部署说明

[当前部署、探测频率与回滚](docs/operations.md) · [源实测记录](docs/source-audit.json) · [新增来源订阅](docs/verified-additions.json) · [设计约定](docs/design.md)

[V9 目录验证、状态恢复与原画备选](docs/netdisk-v9.md) · [V8 一键播放、容量清理与播放优化](docs/netdisk-v8.md) · [V7 多网盘片库与放映室](docs/netdisk-v7.md)。网盘需配置 `CLOUD_ENCRYPTION_KEY` 并由使用者本人扫码；可用画质和速度以实际接口为准。阿里云盘在 v7 使用独立的官方网页登录流程重新接入，历史 v3 的第三方 OpenAPI 授权流程没有启用。旧双人片单入口保持撤下状态。

[双人片单、数据接口与 V2 部署说明](docs/shared-library.md)。V2 需要持久化数据库目录；容器采用 Debian Bookworm 的 Node 22，Compose 示例已包含数据卷。`SITE_ORIGIN` 必须与浏览器访问的网站 origin 一致。

完整的播放器、直播、订阅和环境变量说明见 [上游文档](https://github.com/LibreSpark/LibreTV#readme)。片单数据与播放线路来自不同提供方，能发现影片并不保证有可用播放线路；源的可用性和清晰度随具体影片及网络变化。
